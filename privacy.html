Privacy Policy

Effective November 27, 2026

This policy describes the current TeslafieldAI website, backend and connected AI services. Third-party providers operate their own infrastructure and policies; this policy does not promise that they follow Teslafield's application-level practices.

1. Information used for sign-in

When you sign in with Google, Firebase Authentication verifies your identity. Teslafield uses your Firebase user ID to keep protected API requests and conversations associated with your account. Teslafield does not receive or need your Google password.

2. Conversation history

Chat history is cached in your browser's local storage under an account-specific key. The cloud-history feature can also sync conversations to the default Cloud Firestore database in the Teslafield Firebase project when the project owner has created that database and deployed the repository's owner-only security rules. Cloud sync is not a realtime listener; it synchronizes on sign-in, page focus and local changes. Until the database and rules are configured, conversations remain browser-local. Anyone with access to your unlocked browser profile may be able to access the local cache. It is not encrypted separately by Teslafield.

You can delete an individual conversation or clear saved history from the sidebar; when cloud history is enabled, conversation deletions are also sent to Firestore. Clearing browser data may remove the local cache but does not delete a cloud copy.

Before you sign in, the first message you compose is temporarily kept in session storage in the current browser tab so Teslafield can send that same message after successful sign-in. The temporary draft is cleared after it is handed off or when the browser tab session ends.

3. Chat and model providers

When you send a chat message, Teslafield sends the recent conversation context needed for the response to its backend over HTTPS. The backend forwards that content to the selected model service. The default model is hosted in Teslafield's custom Hugging Face Space, Earthaioa/EARTH_OS_V10_DOCKER. This is a custom public Hugging Face Space, not Hugging Face Inference Providers or an Inference Endpoint. Hugging Face's separate Inference Providers retention statements therefore should not be read as a guarantee for this custom Space. The Space code does not intentionally save chat messages to a permanent application database, but the Space host and its infrastructure may process or retain operational data under their own terms and settings.

Optional OpenRouter models are limited by the backend to model IDs explicitly marked :free; paid model IDs and automatic model fallback are disabled. Requests to OpenRouter are sent with provider routing controls that request Zero Data Retention endpoints and deny providers that collect data beyond transient processing. This can cause a request to fail when no matching endpoint is available. These controls do not erase all service metadata: OpenRouter may retain operational details such as the selected model, token counts, latency and cost, and the selected inference provider processes the prompt to generate a response. Provider eligibility and retention practices can change.

The custom Hugging Face Spaces are currently public endpoints. Google sign-in protects the Teslafield website's API, but it does not make a public Space URL private or prevent a person from visiting a Space directly. Do not send passwords, payment card details, private keys or other highly sensitive information to a model.

4. Speech, voice and files

After sign-in and microphone permission, speech input records audio in your browser and sends it through the Teslafield backend to the custom Hugging Face Space Earthaioa/OpenWhisper-Small for transcription. The transcript is returned to the website. The Space uses Gradio temporary-file handling; its application cache is configured to clean temporary files older than 10 minutes on a one-minute cleanup schedule. This is best-effort application cleanup, not a guarantee about copies or logs held by the hosting platform.

When you use read-aloud, the text, selected language and voice are sent through the backend to Earthaioa/Earthaioa-Kokoro-TTS. The Space creates a temporary audio file and schedules its deletion after 10 minutes; Gradio's temporary cache is also configured for periodic cleanup. These cleanup settings do not control provider or infrastructure logs and cannot guarantee immediate deletion from every system.

File selection in the chat composer currently performs browser-side file type, size and signature checks. Selected files remain on your device; file analysis and file upload through the Teslafield chat composer are not enabled.

Do not record another person without permission. Avoid sending sensitive personal information in audio or text.

5. Security logs

Teslafield's application security audit messages are designed not to record prompt text, conversation bodies, audio, file names, passwords or authentication tokens. They may record the event type, API route, timestamp and a shortened hash derived from the Firebase user ID. Hosting providers and AI services may maintain their own infrastructure, request and network logs under their own policies.

6. Essential storage and cookie choices

Teslafield uses essential browser storage for sign-in state, security-related functionality, appearance preferences, locally saved conversations and your consent choices. Essential storage cannot be disabled without affecting core functionality.

Optional performance analytics and advertising/targeting trackers are not currently enabled by Teslafield. The cookie-choice dialog lets you save a preference for these categories. Accepting optional categories does not cause optional trackers to load while they are not installed.

You can reopen the consent choices at any time using “Your privacy choices” on the first-visit screen.

7. Account deletion

The account deletion control first attempts to delete known cloud conversation contents while the Firebase session is valid, then deletes the Firebase Authentication account and the local conversation cache for that account on the current browser. To prevent an older offline device from silently restoring a deleted conversation, minimal deletion-marker metadata (conversation ID and deletion timestamp) may remain in Firestore. These markers do not contain conversation messages. If cloud cleanup fails, account deletion is stopped and you are asked to retry. This process does not delete data held by Google, Hugging Face, OpenRouter or other external providers, or local browser copies on other devices.

8. Data minimisation

Teslafield aims to collect only information needed to authenticate requests, operate the interface and protect the API. We do not currently operate advertising or analytics trackers on the website.

9. Updates

This policy may be updated when Teslafield features or providers change. Check the effective date above for the current version.
