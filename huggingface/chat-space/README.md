# TESLAFIELD Chat Engine

Local CPU inference with `Qwen/Qwen3-0.6B`. Non-thinking mode is enabled for lower latency. Exposes FastAPI `/chat`, `/stream`, `/health`, and `/info` endpoints.

No paid inference API or external model provider is used.
